Häufige Fragen

Keine Antwort gefunden? Frag in unserer Community 💚

Ist das sicher? Löscht das Programm etwas?

Nichts wird endgültig gelöscht. Alles, was ich wegräume, landet in der Quarantäne und kommt mit einem Klick zurück. Vor Änderungen kann das Programm eine Sicherung deines Mods-Ordners und deiner Spielstände anlegen. Spielstände liest es nur.

Windows meckert über das Programm – was tun?

Das Programm hat noch keine digitale Signatur, deshalb zeigt Windows eventuell „Der Computer wurde durch Windows geschützt“. Klick auf „Weitere Informationen“ → „Trotzdem ausführen“. Lade es nur von dieser Seite oder aus unserem Kanal herunter.

Muss das Spiel auf diesem Computer installiert sein?

Ja, das Programm arbeitet mit dem Ordner von Die Sims 4 auf deinem Computer: Mods, Spielstände, Bibliothek. Jede Version des Spiels aus der EA app oder von Steam passt.

Wie kaufe ich die PRO-Version ohne Krypto?

Klick im Programm auf „💎 PRO-Version“ und wähle einen Tarif – dann öffnet sich eine Rechnung in @CryptoBot. Dort kannst du im P2P-Bereich per Karte USDT mit Rubel, Hrywnja oder Tenge kaufen und die Rechnung bezahlen. Der Aktivierungsschlüssel kommt automatisch ins Programm.

Neuer Computer – wird die PRO-Version übertragen?

PRO läuft auf einem Computer. Klick auf dem alten auf „💎 PRO-Version“ → „Auf einen anderen Computer übertragen“ und gib auf dem neuen deinen Schlüssel ein. Den alten Computer gibt es nicht mehr? Schreib in der Community, dann übertragen wir ihn von Hand.

Wie aktualisiere ich das Programm?

Gar nicht – es aktualisiert sich beim Start von selbst.
