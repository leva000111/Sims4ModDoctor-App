Файли LastException: що це і як знайти за ними зламаний мод

Якщо в папці гри з’явилися файли з назвою lastException, значить, гра впіймала помилку. Лякатися не треба — це не вірус і не поломка комп’ютера. Навпаки, такий файл часто прямо підказує, який мод винен.

Оновлено: 25 листопада 2026

Де лежать ці файли

У папці Документи\Electronic Arts\The Sims 4. Зазвичай вони називаються так:

  • lastException.txt — помилка в логіці гри (часто через мод-скрипт або мод на поведінку);
  • lastUIException.txt — помилка в інтерфейсі (часто через мод, що змінює меню й вікна);
  • lastCrash.txt — запис про виліт гри.

До назви файлу іноді додається номер або дата — це просто різні випадки тієї самої історії.

Це небезпечно?

Сам файл — ні, це просто запис. Але якщо такі файли з’являються знову й знову, значить, щось у грі регулярно ламається. Найчастіше — застарілий мод після патча. Збереження в такій грі краще не перезаписувати, доки причину не знайдено.

Як прочитати файл без програмування

  1. Відкрий файл звичайним «Блокнотом».
  2. Не лякайся довгих рядків — читати все не треба.
  3. Подивися дату файлу в Провіднику (стовпець «Дата змінення») — переконайся, що помилка свіжа, а не місячної давності.
  4. Шукай у тексті слово Mods, назви файлів .ts4script або імена, схожі на нік автора мода. Найчастіше винуватця згадано в самих останніх рядках опису помилки.

Якщо в тексті згадано лише внутрішні файли гри, а модів не видно, — це не означає, що моди ні до чого. Мод міг зламати щось «чужими руками». Тоді допоможе пошук методом 50/50.

Як отримати свіжий і зрозумілий файл

  1. Закрий гру.
  2. Перенеси всі старі файли lastException, lastUIException і lastCrash в окрему папку (або видали — грі вони не потрібні).
  3. Запусти гру й повтори дію, після якої з’являлася помилка.
  4. Тепер у папці буде лише свіжий запис — саме про твою проблему.

Що робити, коли винуватця знайдено

  • Перевір сторінку автора мода — можливо, вже є виправлення для поточної версії гри.
  • Якщо оновлення немає — прибери мод із Mods і зачекай.
  • Якщо не впевнена — покажи файл у спільноті гравців: досвідчені модери часто розуміють його з першого погляду.

Як правильно попросити про допомогу

Помічникам у чатах зазвичай потрібно одразу кілька речей: файл помилки, список модів, версія гри. У Sims 4 Mod Doctor є безкоштовний «Звіт для допомоги»: один zip з усім потрібним для чату підтримки, де ім’я користувача Windows приховано. А безкоштовна функція «Коди помилок гри» по-людськи пояснить незрозумілі коди на кшталт 123:4a5b6c7d.

Ще простіше — почати з безкоштовної перевірки модів: вона знаходить застарілі й зламані файли раніше, ніж ті почнуть сипати помилками. У PRO-версії автопошук сам запускає гру, читає помилки й шукає винуватця.
