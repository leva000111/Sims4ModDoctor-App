Mods not showing up in the game: 8 causes and fixes

The files are in the folder, but in the game there's no new hairstyle and no new interaction. Almost always it's one of the eight small things below. Go through them in order — the first three are the most common.

Updated: November 25, 2026

1. Mods are disabled in the game settings

After every update the game switches mods off. And script mods have a separate setting.

  1. Open Game Options → Other.
  2. Tick Enable Custom Content and Mods and Script Mods Allowed.
  3. Click Apply and restart the game.

An easy way to tell whether the game sees your mods: with mods enabled, it usually shows a window on the main menu listing the mods it found. No window and no mods on the list means the game doesn't see them.

2. Mods are in the wrong folder

The right folder is Documents\Electronic Arts\The Sims 4\Mods. Not the game's install folder and not Downloads.

If you have several "The Sims 4" folders (for example after changing the Windows language or reinstalling), the game only reads one — the one with your latest saves and the Options.ini file.

3. Your Documents folder lives in OneDrive

If Windows syncs Documents with OneDrive, your PC ends up with two Documents folders: the regular one and OneDrive\Documents. The game uses whichever one Windows currently points to — and doesn't see mods placed in the other.

Another trap: OneDrive can keep files "online-only" (a cloud icon next to the name). The game can't read those. Right-click the The Sims 4 folder and choose "Always keep on this device".

4. A script mod is nested too deep

The game only reads .ts4script files placed directly in Mods or one subfolder down:

  • ✅ Mods\MyMod\mod.ts4script
  • ❌ Mods\Scripts\MyMod\mod.ts4script — too deep.

5. Regular mods are buried more than five folders deep

You can organize .package files into folders, but no more than five levels deep inside Mods. Anything deeper is skipped.

6. The mod is still zipped

The game only reads .package and .ts4script files. Unpack .zip, .rar and .7z archives and remove the archive itself from Mods.

One exception: a .ts4script file is technically an archive too. Don't unpack it — just put it in Mods as it is.

7. The mod needs a pack or another mod

Clothes and furniture made from a pack won't show up if you don't own that pack. And some mods only work together with the creator's "core" mod — this is usually stated on the download page.

8. The mod is outdated or corrupted

An old version of a mod can silently stop working after a patch. So can a file that didn't finish downloading. Download the mod again from the creator's page and delete the old version. If that doesn't help, find the problem mod with the 50/50 method.

While you're at it, delete the cache — localthumbcache.package in Documents\Electronic Arts\The Sims 4. The game rebuilds it.
