LastException files: what they are and how to use them to find a broken mod

If files named lastException show up in your game folder, the game has caught an error. No need to panic — it's not a virus and your PC isn't broken. In fact, a file like this often points straight at the mod to blame.

Updated: November 25, 2026

Where these files are

In the Documents\Electronic Arts\The Sims 4 folder. They're usually called:

  • lastException.txt — an error in the game's logic (often caused by a script mod or a behavior mod);
  • lastUIException.txt — an error in the interface (often caused by a mod that changes menus and windows);
  • lastCrash.txt — a record of a game crash.

Sometimes a number or a date is added to the file name — those are just separate instances of the same story.

Is it dangerous?

The file itself isn't — it's just a record. But if these files keep showing up again and again, something in the game is breaking regularly. Most often it's an outdated mod after a patch. Better not to overwrite your saves in that game until you've found the cause.

How to read the file without any coding

  1. Open the file in plain Notepad.
  2. Don't let the long lines scare you — you don't need to read all of it.
  3. Check the file's date in File Explorer (the "Date modified" column) to make sure the error is recent and not a month old.
  4. Look in the text for the word Mods, .ts4script file names, or names that look like a mod creator's nickname. Most often the culprit is mentioned in the very last lines of the error description.

If the text only mentions the game's own internal files and no mods, that doesn't mean mods are off the hook. A mod may have broken something "through someone else's hands". In that case, the 50/50 method will help.

How to get a fresh, clear file

  1. Close the game.
  2. Move all the old lastException, lastUIException and lastCrash files to a separate folder (or delete them — the game doesn't need them).
  3. Launch the game and repeat whatever caused the error.
  4. Now the folder will only have a fresh record — about your problem specifically.

What to do once you've found the culprit

  • Check the creator's page — there may already be a fix for the current game version.
  • No update? Take the mod out of Mods and wait.
  • Not sure? Show the file in a player community: experienced modders can often read it at a glance.
