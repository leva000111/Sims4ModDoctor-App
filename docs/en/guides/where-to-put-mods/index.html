How to install mods the right way: where the files go

Most "broken" mods are actually just in the wrong place. Here's a short cheat sheet: which file goes where and what to turn on in the game so everything works the first time.

Updated: November 25, 2026

The main folder is Mods

All mods and CC live in Documents\Electronic Arts\The Sims 4\Mods. If it's not there, launch the game once and it will create the folder itself. Don't put mods in the game's install folder.

Which file goes where

FileWhat it isWhere it goes
.packageclothes, hair, furniture, behavior modsin Mods, subfolders are fine — no more than 5 levels deep
.ts4scriptscript moddirectly in Mods or one subfolder down — no deeper
.trayitem, .blueprint, .bpi, .hhi, .sgi, .householdbinary, .room, .rmihouseholds, lots and roomsin the Tray folder, not in Mods
.zip, .rar, .7zarchiveunpack it, and don't put the archive itself in Mods

Step by step: installing a new mod

  1. Download the mod from the creator's page and read the description: does it need any packs or another mod by the same creator?
  2. If you got an archive, unpack it.
  3. Create a folder in Mods with a clear name, for example Mods\Hair or Mods\CreatorName.
  4. Put the mod's files there. If the mod has both a .package and a .ts4script, keep them together, in the same folder.
  5. If it's an update, delete the old version of the mod first.
  6. Launch the game and make sure Enable Custom Content and Mods and Script Mods Allowed are ticked in Game Options → Other. If you just turned them on, restart the game.

How to organize mods so you don't suffer later

  • Keep CC and gameplay mods separate. CC rarely breaks after a patch, but gameplay mods often do. That way, after an update you know right away what to check.
  • One folder per creator or per big mod. Easy to update: delete the folder, drop in the new version.
  • No more than one subfolder for scripts. That's a game limitation, not a suggestion.
  • Keep a backup. Before big changes, copy your Mods folder — getting your working setup back will take a minute.
