Un patch est sorti et tes mods sont cassés : que faire

Après une mise à jour du jeu, une partie des mods arrête presque toujours de fonctionner. C'est normal, et ça se répare. Voici l'ordre des étapes qui remet ton jeu en marche sans rien casser pour de bon.

Mis à jour le: 25 novembre 2026

Pourquoi les mods cassent après un patch

Une mise à jour modifie le code du jeu et ses tables internes. Les mods qui s'appuient sur les anciennes versions de ces tables se mettent à faire des erreurs. Les plus touchés :

  • les mods de script — les fichiers .ts4script : ils interviennent directement dans le code du jeu ;
  • les mods qui modifient l'interface — nouveaux boutons, menus, fenêtres ;
  • les mods de gameplay — nouvelles interactions, traits de caractère, carrières.

Les vêtements, coiffures, meubles et autres CC survivent en général sans problème à un patch. Ne commence donc pas par tout supprimer : vérifie d'abord les « suspects ».

Étape 1. Réactive les mods

Après chaque mise à jour, le jeu désactive lui-même les mods et affiche un avertissement. Si tes mods ont « disparu » mais que le jeu ne plante pas, c'est sûrement pour ça.

  1. Ouvre Options de jeu → Autre.
  2. Coche les deux cases : celle du contenu personnalisé et des mods, et celle des mods de script.
  3. Clique sur « Appliquer » et redémarre complètement le jeu — sans redémarrage, les mods ne seront pas chargés.

Étape 2. Fais une copie avant de toucher à quoi que ce soit

Copie quelque part les dossiers Mods et Saves de Documents\Electronic Arts\Les Sims 4. Ça prend deux minutes, et chaque essai pourra être annulé.

Tant que tes mods ne sont pas réparés, ne sauvegarde pas tes familles importantes. Un mod cassé peut écrire dans ta sauvegarde une erreur qui restera même après le retrait du mod.

Étape 3. Retire les mods de script et teste le jeu

  1. Crée un dossier sur ton bureau, par exemple « Mis de côté après le patch ».
  2. Déplace-y tous les mods de script : les fichiers .ts4script et les dossiers de mods où ils se trouvent (avec leurs .package — un mod a souvent les deux fichiers).
  3. Lance le jeu.

Si le jeu fonctionne, le coupable est parmi les mods de script mis de côté. Sinon, le problème vient des fichiers .package ordinaires : passe à la recherche 50/50.

Étape 4. Mets à jour les mods mis de côté

Les créateurs de mods populaires publient en général une mise à jour dans les jours qui suivent un patch. Pour chaque mod mis de côté :

  • va voir la page du créateur — on y indique souvent si la version est compatible avec le dernier patch ;
  • télécharge la nouvelle version et supprime l'ancienne — deux versions du même mod dans le dossier provoquent souvent des erreurs à elles seules ;
  • remets les mods un ou deux à la fois, et teste le jeu à chaque fois.

Si le créateur indique que le mod est « cassé » et qu'il n'y a pas encore de mise à jour, attends simplement. Ne le remets pas dans le jeu trop tôt.

Étape 5. Vide le cache

Supprime le fichier localthumbcache.package dans le dossier Documents\Electronic Arts\Les Sims 4. C'est le cache des images : le jeu le recrée, et l'ancien provoque parfois, après un patch, des erreurs bizarres et des icônes « vides ».

Étape 6. Ça n'a pas suffi ? Trouve le coupable avec la méthode 50/50

Si le jeu plante encore ou bloque au chargement, c'est qu'un mod ordinaire est cassé. Le moyen le plus rapide de le trouver, c'est la méthode 50/50 : tu caches la moitié des mods, tu testes, tu réduis le cercle. Même parmi des milliers de fichiers, le coupable est trouvé en 10–12 lancements.

Les erreurs fréquentes après un patch

  • Supprimer tous les mods d'un coup. Il faudra ensuite retrouver et retélécharger des centaines de fichiers. Mets de côté au lieu de supprimer.
  • Installer la nouvelle version par-dessus l'ancienne avec un autre nom de fichier. Les deux se retrouvent dans le dossier et entrent en conflit.
  • Sauvegarder « pour tester » avec des mods non vérifiés. Les erreurs peuvent rester dans la sauvegarde.
  • Garder des archives dans Mods. Le jeu ne lit pas les .zip ni les .rar : il faut les décompresser.

Comment faire tout ça plus vite

Avec Sims 4 Mod Doctor, tu n'as pas à faire la plupart de ces étapes à la main :

  • la recherche 50/50 gratuite cache elle-même la moitié des suspects — toi, tu lances le jeu et tu dis si ça va mieux ;
